# Достижения Надежды

Личный пиксельный журнал достижений для Надежды Федотовой. Работает полностью в браузере: записи сохраняются в `localStorage`, без сервера и базы данных.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

Проект автоматически публикуется на GitHub Pages при каждом пуше в ветку `main`. В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**.
