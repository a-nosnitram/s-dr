# Достижения Надежды

Личный пиксельный журнал достижений для Надежды Федотовой. Работает полностью в браузере: записи сохраняются в `localStorage`, без сервера и базы данных.

## Локальный запуск

```bash
npm install
npm run dev
```

## Публикация

После сборки готовый сайт находится в папке `docs`. Для публикации напрямую из ветки выберите **Settings → Pages → Deploy from a branch → `main` → `/docs`**.

Перед отправкой изменений выполните `npm run build` и добавьте обновлённую папку `docs` в коммит.
